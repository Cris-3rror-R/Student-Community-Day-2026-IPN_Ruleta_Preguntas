# Student-Community-Day-2026-IPN_Ruleta_Preguntas
Esta es la actividad que fue desarrollada para el Student Community Day 2026 IPN, por parte del SBG Institute Tecnology at Ocotlan para crear una dinamica divertida que consistia en responder 4 preguntas aleatorias correctas para llevarse premios que teniamos.

El proyecto se diseño debido que desconociamos que hubiera internet estable para la página original.
Entonces decidir realizar un página web en localhost debido que no valia la pena subirla usando Vercel o con AWS Amplify.
En vez de utilizar una base de datos como SQL, Postgres o Supabase decidir crear un TDA para introducir las preguntas y respuestas en el archivo Preguntas.js.
La parte de Ruleta.js esta toda la parte de la ruleta.
En principal está las partes principal del proyecto junto con Main.html
En el apartado de style.css esta todos los detalles visual para manterner la identidad visual.
